# SDF World Importer

Loads Gazebo SDF worlds (models, meshes, poses) into a Unity scene at runtime (`SdfWorldImporter`).

Part of [Unity_ROS2_Robot_Simulator](https://github.com/REACT-ROBOT/Unity_ROS2_Robot_Simulator).
Add to another project via `Packages/manifest.json`:

```json
"com.react-robot.sdf-world": "https://github.com/REACT-ROBOT/Unity_ROS2_Robot_Simulator.git?path=/Packages/SdfWorld#<commit>"
```

No additional dependencies.

---

Gazebo の SDF ワールド(モデル・メッシュ・姿勢)を実行時に Unity シーンへ読み込む(`SdfWorldImporter`)。
